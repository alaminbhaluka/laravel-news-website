TRIBUNE BANGLA WORDPRESS THEME
Version: 1.0.0

Installation:
1. Upload the tribune-bangla folder to wp-content/themes/.
2. Activate "Tribune Bangla" from Appearance > Themes.
3. Set a custom logo in Appearance > Customize > Site Identity.
4. Assign menus in Appearance > Menus.
5. Add widgets under Appearance > Widgets.

This theme uses WordPress native Posts, Categories, Tags, Pages, Comments and Media Library.
It is a theme foundation. Legacy Laravel-specific workflows (reporter roles, advertisements,
photo/video gallery data, newsletter subscriptions, SEO options and migration) require
a companion plugin and a verified data migration before the production switch.
