TRIBUNE BANGLA WORDPRESS THEME
Version: 1.0.0

INSTALLATION
1. Copy tribune-bangla to wp-content/themes/.
2. Copy tribune-bangla-core to wp-content/plugins/.
3. Activate the Tribune Bangla theme and Tribune Bangla Core plugin.
4. Set the logo in Appearance > Customize > Site Identity.
5. Assign the primary and footer menus in Appearance > Menus.
6. Add widgets under Appearance > Widgets.
7. Enable public registration under Settings > General if public account registration is required.

THEME FEATURES
- Bengali-first responsive newspaper layout.
- Homepage breaking-news strip, featured stories, category sections and sidebar.
- Category/archive/search listings, single news, pages, comments and 404 template.
- WordPress native Posts, Categories, Tags, Pages, Comments and Media Library.
- Breaking-news checkbox in the post editor.
- Custom logo, primary/footer menus, widgets and basic Customizer settings.

CORE PLUGIN FEATURES
- Photo/video gallery content type.
- Advertisement management content type.
- Newsletter subscriber management and [tribune_newsletter] shortcode.
- Contact-message management and [tribune_contact_form] shortcode.
- Mobile number profile field and [tribune_mobile_account] login/registration shortcode.
- Contact phone/email settings.

IMPORTANT
This is a development foundation, not a production-ready migration. SMS/OTP verification,
reporter/editor role mapping, full SEO/social-login/mail settings, ad placement controls,
geographic news filters, gallery front-end layouts, Laravel data import and end-to-end
security/compatibility testing still need implementation and verification. Do not point the
production domain or overwrite any existing database until migration and acceptance testing
are completed.
